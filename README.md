# Life — статическая PWA для GitHub Pages

Приложение из [`egor948/life`](https://github.com/egor948/life), переведённое с Next.js + PostgreSQL на статическую сборку Vite. Весь интерфейс и функции сохранены: «Сегодня», календарь (день / 3 дня / неделя / месяц / год / сводка), задачи, цели и подцели, привычки, статистика, поиск, напоминания, темы, экспорт и импорт.

## Что изменено

- **Нет сервера и базы данных.** Задачи, события, цели, привычки и настройки сохраняются в `localStorage` на устройстве. Приложение полностью работает офлайн.
- **Уведомления.** Серверный web-push заменён локальными напоминаниями и service worker. На iPhone они работают, пока Life открыт или когда вы в него возвращаетесь; фоновая доставка при полностью закрытом приложении на статическом хостинге невозможна.
- **PWA.** Манифест, PNG-иконки, iOS-мета, офлайн-кэш и инструкция установки в «Настройках».
- **Публикация.** GitHub Actions собирает `dist` и публикует его на GitHub Pages.

Новые/изменённые файлы по сравнению с Next.js-версией: `index.html`, `src/App.tsx`, `src/main.tsx`, `src/index.css`, `src/lib/storage.ts`, `src/lib/push-client.ts`, `src/store/store.tsx`, `public/manifest.json`, `public/sw.js`, `public/icons/*`, `.github/workflows/deploy.yml`. Компоненты интерфейса перенесены как есть; тексты в настройках и центре уведомлений обновлены под статическую версию.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

1. Загрузите этот проект в репозиторий на GitHub (ветка `main`).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. Сделайте push в `main` или запустите workflow **Deploy Life PWA to GitHub Pages** вручную во вкладке **Actions**.
5. Через пару минут приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

В проекте включён `vite-plugin-singlefile`: JS и CSS попадают в один `index.html`, поэтому приложение корректно работает из подпапки GitHub Pages и не требует настройки `base`. Манифест, service worker и иконки подключаются относительными путями.

## Установка на iPhone

1. Откройте адрес приложения **в Safari**.
2. Нажмите **«Поделиться»**.
3. Выберите **«На экран „Домой“»** и подтвердите.
4. Запускайте Life с иконки на домашнем экране — без адресной строки, с поддержкой офлайна.
5. При необходимости включите уведомления: **Настройки → Системные уведомления → Включить**.

> Важно: данные хранятся на каждом устройстве отдельно. Для переноса используйте **Настройки → Экспорт** и **Импорт**. На iOS очистка данных Safari удаляет и данные Life, поэтому делайте резервные копии.
